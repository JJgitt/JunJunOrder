2026-09-10 货号兜底更新已发布：识图货号为空时使用商品名称。版本镜像 `hongyun-order-app:sku-20260910`，旧镜像 `hongyun-order-app:before-sku-20260910`；数据库备份位于 `/home/junjun/hongyun-backup-sku-20260910/database.dump`。

本次为避免构建挤占线上资源，在 `/home/junjun/hongyun-release-sku-20260910` 使用独立容器构建：内存上限 1GB、内存加交换总上限 2GB、1 核 CPU、`NODE_OPTIONS=--max-old-space-size=640`，构建命令 `npm run build -- --webpack`。成功后以 `deploy/Dockerfile.prebuilt` 打包并切换应用镜像。服务器配置和数据卷保持不变。后续在这台 2GB 服务器更新应继续采用限额构建，不直接运行无限额的 `docker compose up --build`。

在服务器项目目录运行：

```bash
sudo docker compose -f compose.yaml -f deploy/compose.server.yaml ps
sudo docker compose -f compose.yaml -f deploy/compose.server.yaml logs --tail=100 app
sudo docker compose -f compose.yaml -f deploy/compose.server.yaml up -d --build app
```

由于服务器连接 Docker Hub 超时，Node 镜像通过华为云地址下载后标记为 node:22-alpine；PostgreSQL 镜像地址在覆盖文件中指定。后续升级应重新核验来源与版本。Caddy 未启用，使用 deploy/hongyun.nginx.conf。
