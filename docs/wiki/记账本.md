# 管理员月度毛利记账本

## 使用和边界

入口为管理员“我的 → 记账本”，默认收起，展开后选择记账月份、填写毛利金额及选填备注。首次选择的月份以服务器当前时间和时区为准；选择已记录月份或点击历史记录的编辑按钮会回填该月数据，保存后更新原记录，不产生重复月份。支持正数、零及负数，最多两位小数；金额必须填写，备注最多 500 字。

这是所有管理员共享的人工记账本，不是按管理员划分的个人账本。采购员无入口，接口也拒绝采购员读写。历史记录按月份倒序，时间按服务器时区显示。它与自动计算的月采购额、月销售额、月利润（估）及采购结款完全独立：手工记账不改订单、库存或统计口径。

页面读取失败时展示重试，并禁止把未成功读取的数据当作空账本保存。提交中禁止重复保存和切换月份，保存失败保留草稿。手机输入字号至少 16px，避免 iPhone 聚焦输入框自动缩放。

## API 和持久化

- `GET /api/account-book`：登录并验证管理员后读取全部月份，返回 `{ records }`，按月份倒序，不缓存。
- `POST /api/account-book`：同源检查及管理员鉴权，接收 `{ month, grossProfit, note? }`，返回 `{ record }`。按月份 upsert，保留首次创建信息，更新最后修改信息；与 `save_monthly_gross_profit` 审计在同一事务内提交。
- `lib/account-book.ts`：月格式验证、精确整数分转换及共享响应类型。拒绝空金额、非有限数字、超过两位小数及 PostgreSQL integer 范围外的金额，不静默舍入或截断。

`db/schema.ts` 的 `monthlyGrossProfits` 对应 `monthly_gross_profits`；新增迁移为 `drizzle/0016_monthly_gross_profits.sql`，由现有启动迁移器自动执行，不修改已执行迁移。

- `month`：文本主键，严格 `YYYY-MM`，年份 0001～9999，月份 01～12。
- `gross_profit_cents`：非空整数，单位分，范围 -2147483648～2147483647。
- `note`：非空文本，默认空字符串，数据库约束最多 500 字。
- `created_by` / `updated_by`：首次记录 / 最后修改的管理员 ID，引用 `users`；删除账号时置空，不删除月度记录。
- `created_at` / `updated_at`：带时区时间戳，分别为首次记录和最后修改时间。

API 仅返回月份、元金额、备注和创建/修改时间，不返回操作者账号资料。

## 回归验证

`tests/account-book.test.mjs` 覆盖真实路由的权限、月份、金额、备注校验、upsert 及审计失败回滚；`tests/account-book.integration.mjs` 使用 CI 隔离 PostgreSQL 验证迁移、整数分、唯一月份及持久化行为。UI 测试覆盖加载、回填、保存和错误状态。生产验收只做读取和健康检查，不向真实记账本插入测试账目。
